# B 站信息查询 · Windows 桌面版 v1.1

## 打开程序

解压整个文件夹，双击 **BilibiliInfo.exe**。

如替换旧版，请先关闭旧程序，重新下载并解压；窗口标题应为 **B 站信息查询 v1.1**。

适用于 Windows 10 / 11，使用系统自带的 .NET Framework 4.x。无需安装 Python、PyCharm、requests 或其他第三方依赖，也无需管理员权限。程序不安装后台服务。

## 查询方式

1. 选择“视频信息”或“UP 主信息”。
2. 粘贴链接，每行一个，或用英文／中文逗号分隔。逗号后可以有空格。
3. 点击“开始查询”。可随时点击“停止”，已经查到的结果会保留。

**视频信息**：支持完整视频链接、BV 号以及 b23.tv 短链接。显示标题、UP 主、播放量、点赞量和评论量。

**UP 主信息**：支持主页链接、UID、视频链接、BV 号以及 b23.tv 短链接。显示 UID、粉丝数和关注数。输入视频链接时会自动找出视频的 UP 主；直接输入主页或 UID 时，原有的粉丝接口不包含昵称，因此显示 `UID xxxxxx`。

输入格式示例：

```text
https://www.bilibili.com/video/BVxxxxxxxxxx/
BVxxxxxxxxxx
```

上面的 BV 是格式占位符，使用时请换成真实的视频链接或 BV 号。

UP 主主页的格式是 `https://space.bilibili.com/数字UID`。仅支持 BV 视频链接，不支持旧式 av 视频链接；短链接若无法跳转，请在浏览器打开后复制完整链接。

## 查看和保存

- 双击结果行查看详情，包括原始链接和查询时间。
- “复制结果”复制全部结果。
- “导出 CSV”保存到自己选择的位置，可用 Excel 打开。CSV 为 UTF-8 BOM 编码，保留完整数字；导出文本会防止被 Excel 当成公式执行。
- 横向滚动表格可以查看粉丝、关注及错误提示等列。
- 每次开始查询会替换窗口中的上一批结果。需要保存时请先导出。

同一批会去掉完全相同的重复输入，最多 100 条。不同写法的同一视频链接仍会分别查询。数据是查询时的公开累计数据，不是历史趋势，也不自动刷新。

## 查询失败怎么办

v1.1 增加视频接口兼容处理：只有原视频接口返回 HTTP 412 或接口错误码 -412 时，等待一秒并尝试 `/x/web-interface/wbi/view` 一次。成功后，本次程序运行中的后续视频查询会直接使用兼容接口，不重复请求已被拒绝的旧接口。两个接口都失败时会说明失败环节，不无限重试。UP 主主页／UID 查询仍使用原粉丝接口。

错误会显示在对应结果行，其他链接继续查询。程序检查链接格式、HTTP 状态、B 站接口状态码及响应结构；单次请求超时为 20 秒，相邻查询之间有短暂间隔。

B 站接口可能因访问验证、登录限制、网络问题或接口变化而失败。请稍后再试，或减少每批链接数量。请求头只是正常的浏览器标识，不能保证绕过访问限制。程序不会收集 Cookie、登录账号或上传查询结果；查询时只访问 B 站相关域名，导出文件只保存到你选择的位置。

## 源码和重新编译

为让 Windows 版独立运行，本版把原 Python 脚本的核心查询逻辑改写成 C# / Windows Forms，保留原来使用的两个接口：

- 视频：`https://api.bilibili.com/x/web-interface/view?bvid=...`
- 视频兼容接口：`https://api.bilibili.com/x/web-interface/wbi/view?bvid=...`
- 粉丝／关注：`https://api.bilibili.com/x/relation/stat?vmid=...`

源码在 `src/BilibiliInfo.cs`，修改后双击 `build_windows.cmd` 重新生成 exe。打包中没有 Python 解释器。

## 验证范围

已编译为 Windows .NET 图形可执行文件，并在 Linux 的 Mono 兼容运行时验证链接解析、离线模拟接口、错误处理、取消、CSV 导出，以及窗口中的正常／错误结果显示。

v1.1 额外验证 HTTP 412 和接口 -412 的单次回退、后续查询使用兼容接口、正常视频不回退、404／403／429 不回退、双接口失败、UP 主接口错误不触发视频回退、回退间隔取消，以及通过视频链接查询 UP 主的兼容路径。兼容处理参照 BBDown 维护者的接口适配记录：https://pypi.org/project/bbdown/0.0.1a0/ 。

当前环境无法连通 B 站 API，未完成真实在线查询；也未在真正的 Windows 系统上运行验证。联网查询仍取决于你所在网络和 B 站接口的可用情况。

本程序是根据你提供的脚本制作的个人工具，与 B 站官方无关。
